# 桂工赛智通

**面向大学生竞赛服务的智能体** · 参赛类别：数智新技艺 → 智能体 AIGC 应用

让每一场比赛，都找到最适合你的打开方式。

## 这是什么

一个帮助桂林理工大学学生查比赛、选赛道、判断报名资格、列材料清单、生成参赛方案的智能体。第一版知识库已收录：

- 2026 年桂林理工大学大学生网络文化节（7 个赛道）
- 2026 年桂林理工大学网络教育优秀作品推选展示大赛（教师/学工队伍 5 类作品）
- 84 项全国大学生权威竞赛（依据 2025 年教育部认可目录，含各赛事官网入口）

## 怎么运行

纯前端、无需服务器、可离线运行。双击打开 `index.html` 即可（建议用 Edge / Chrome）。

```text
outputs/guigong-saizhitong/
├── index.html    页面结构
├── styles.css    样式
├── kb.js         知识库（结构化赛事数据）
├── kb_whitelist.js  84 项全国权威竞赛库
└── app.js        智能体逻辑（意图识别 / 匹配 / 生成）
```

## 五个核心功能

| 功能 | 你可以这样问 |
| --- | --- |
| ① 比赛查询 | “最近有什么比赛” |
| ② 赛道匹配 | “我是计算机专业大二，适合报哪个” |
| ③ 报名条件判断 | “我能不能参加” |
| ④ 材料清单 | “数智新技艺需要准备什么” |
| ⑤ AI 参赛助手 | “帮我想作品创意和 PPT 结构” / “设计测试案例” |
| ⑥ 白名单竞赛 | “白名单竞赛有哪些” / “数学建模是什么” / “我适合参加什么白名单竞赛” |

## 扩充知识库的两种方式

1. **界面内添加**：点侧边栏「添加赛事」，填写名称 / 对象 / 主办单位 / 截止日期 / 报送入口即可（保存在浏览器本地）。
2. **直接改 `kb.js`**：按现有 `competitions` 结构追加新赛事，刷新页面即生效，适合把更多学校通知录入。

## 后续建议补充的材料

格式不限（Word / PDF / 网页截图 / 公众号链接），发给我或放进文件夹即可，我来解析入库。每份材料尽量包含：

- 主办单位、面向对象
- 时间节点（报名 / 提交 / 截止）
- 报名条件、赛道或类别
- 材料清单、提交方式
- 奖励设置、联系方式

优先补充：互联网+ / 挑战杯 / 数学建模 / 学科竞赛，以及奖学金、三好学生、助学金、就业实习等通知。
